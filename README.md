# SCADA Bulgaria — GitHub Pages

Уеб версия на български SCADA мониторинг панел.

## Стартиране

Отвори `index.html` локално или качи трите файла в GitHub repository.

### GitHub Pages

1. Създай repository.
2. Качи `index.html`, `style.css` и `app.js`.
3. В **Settings → Pages** избери **Deploy from a branch**.
4. Избери `main` и `/root`.
5. Запази. GitHub ще публикува панела като уеб страница.

## Забележка

Тази версия е **front-end демонстрация**. Данните се генерират локално за демонстрация на SCADA интерфейса. Реалните ESO данни могат да бъдат свързани отделно чрез backend/API.
